# SEC-001: Quote page builds table rows with innerHTML from values

**From:** `npm run security:scan` (framework v1, CR-07), 2026-11-25
**Type:** Security

`app/public/index.html` line 36 inserts the line description into `innerHTML` through string
interpolation. Today it is only called with constants, but any future caller that passes user text
opens a cross-site scripting path. The automated scan now blocks every build until this is fixed.

Worked scenario: **S11** (security blocks an otherwise correct change), delivered live through the stages.
